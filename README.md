# 💰 Crypto Portfolio Balancer (JS)

A JavaScript utility designed to manage data structures and simulate financial portfolio allocations. This project demonstrates how to manipulate complex data using Arrays and Objects.

## 🚀 Key Features
- **Dynamic Valuation:** Calculates the real-time USD value of different cryptographic assets based on quantity and price.
- **Allocation Metrics:** Computes the percentage distribution (weight) of each token relative to the entire portfolio.
- **Clean Output:** Generates a structured terminal report of holdings and total net worth.

## 🛠️ Programming Concepts Applied
- **Objects & Arrays:** Storing structured asset data in key-value pairs.
- **Array Methods:** Utilizing `.forEach()` to iterate over collections and process financial metrics.
- **Arrow Functions:** Implementing modern and clean ES6 JavaScript syntax.
